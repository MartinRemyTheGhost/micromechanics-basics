# Micromechanics Basics

Exemples Python simples pour comprendre l’élasticité,
l’homogénéisation et la micromécanique des matériaux.

## Objectif

Relier les notions théoriques de mécanique à des exemples
numériques accessibles et documentés.

## Exemples prévus

- Calcul des modules élastiques d’un matériau isotrope.
- Décomposition sphérique et déviatorique des tenseurs.
- Estimation des propriétés élastiques de matériaux composites.

Les scripts seront ajoutés progressivement.
